Random Password Generator (CLI Version)
Project Description :
This is a Command-Line based Random Password Generator developed using Python. The program allows users to generate secure passwords by selecting the desired length and choosing whether to include letters, numbers, and symbols.

Features :
User-defined password length
Option to include:
Letters (A–Z, a–z)
Numbers (0–9)
Symbols (!, @, #, etc.)
Input validation for correct length
Random password generation using Python modules

Technologies Used :
Python
random module
string module

How It Works :
The program takes user input for password length and character preferences. It then combines the selected character sets and generates a random password using the random.choice() function.

Conclusion :
This project demonstrates Python fundamentals such as functions, conditional statements, loops, input validation, and randomization to create secure passwords.
